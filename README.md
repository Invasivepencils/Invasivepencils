# Anthony Benavides

Mathematics & Computer Science at UC San Diego · Regents Scholar

I build research tools around questions I care about: what changes a football matchup, and what a community statistic can actually tell us. My focus is making the assumptions visible and the results reproducible.

## Selected work

### Gridiron Lab

A football research notebook built on Bayesian team-strength contrasts, joint covariance, injury scenarios, and chronological backtesting. The browser experiment uses fictional teams so the method can be inspected without implying live NFL accuracy.

**[Try the experiment →](https://invasivepencils.github.io/gridiron-lab/)** · [Read the code and methodology](https://github.com/Invasivepencils/gridiron-lab)

### Attainment Atlas

A field guide to historical California college-degree attainment. Search communities, compare like geographic areas and population groups, and export the evidence. Built with Java, Spring Boot, and a companion browser explorer.

**[Explore a community →](https://invasivepencils.github.io/education-statistics-compiler/)** · [Read the code and data notes](https://github.com/Invasivepencils/education-statistics-compiler)

I value careful comparisons, timestamped inputs, clear uncertainty, and tools that another person can actually use. Both projects include automated checks and documented limitations.
